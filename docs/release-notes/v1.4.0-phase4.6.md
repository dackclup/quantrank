# v1.4.0-phase4.6 — Honest re-validation harness

Released: 2026-05-27

## Headline

Closes the **Phase 4.6 honest re-validation harness epic** — ships 5 new
validation modules, 1 new ingest module (historical S&P 500 membership),
and a CLI honest-baseline report generator. The chain (Hou-Xue-Zhang
2020 RFS survivorship-bias correction → universe-drift partition →
git-archived rankings.json loader → forward-return loader → per-pillar
Spearman IC → manipulation distribution shift → honest-baseline skeleton)
provides the **infrastructure** to retrospectively answer "what would
this composite have ranked at date X under the universe that actually
existed on date X" — closing the methodological gap that survivorship
bias on the static S&P 500 list left open since Phase 4h.

Defense layer headline count **unchanged at 33 declared boolean flags**
(7 active vetoes + 26 annotates + reserved slots). Phase 4.6 ships
infrastructure only — no new flags, no threshold changes, no Rule 16
semantics shift.

Schema bump `0.10.6-phase4.5e` → **`0.10.7-phase4.6`** (PATCH; additive
universe-provenance `Metadata` fields — no consumer migration).

This release ships the **harness**. The numeric cells in
`docs/research/honest-baseline-2026-05-27.md` §2-5 (per-pillar IC /
PBO/DSR / manipulation distribution / survivorship delta) are **TBD**
pending a warm-CI execution session — deferred to v1.4.x or v1.5.0
follow-up, gated on price-cache warmth + rankings.json git history
depth.

### Honest-baseline disclaimer ladder (codified)

The new `scripts/generate_honest_baseline.py` CLI pins the following
framing as a stderr banner on every text-mode run and as
`__banner__` in every JSON-mode payload:

- **Naive baseline**: any in-sample IC / Sharpe is **before** the
  McLean-Pontiff 2016 *JF* **32% out-of-sample decay** and **before**
  frictions of **≥ 30 bp / leg** (Kissell-Glantz 2003)
- **Honest α ceiling**: **2-5% net annualized** for a long-only
  US-large-cap composite at this universe size and rebalance cadence;
  anything higher is in-sample artifact territory
- **Universe**: S&P 500 only (~502 names). Composite is NOT calibrated
  for SMID, microcap, OTC, or non-US equity
- **Rule 16 (sacred)**: defense-layer flags annotate-then-veto a
  Top-N badge; they NEVER retroactively modify a composite score.
  Honest re-validation respects this — the harness reads the
  composite as-shipped, not a retro-fitted one
